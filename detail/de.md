# OpenCode Go cost/peak

Das Band über dem Eingabefeld zeigt den Tarif des aktuellen Modells und seinen Preis pro 1M Tokens.

- **Spitze** — rosa, mit der Restzeit bis zum Periodenende.
- **Nebenzeit** — grün, ebenfalls mit Countdown.
- **Einheitlich** — blau: Das Modell hat keine Spitzen- oder Nebenzeit.
- **Kostenlos** — grün: Alle Tokens kosten 0 $, ohne Zeitraum.

Links steht der Preis des aktuellen Tarifs (Eingabe · Ausgabe · Cache, dazu Cache-Schreiben, wenn das Modell es berechnet); rechts die Phase, das Periodenende in deiner Zeitzone und die Restzeit.

Die Einstellungen liegen auf dieser Seite: Modellkatalog, Stoßzeiten, Verhalten, eigenes CSS und Zurücksetzen. Das Plugin folgt immer der DSH-Oberflächensprache.
