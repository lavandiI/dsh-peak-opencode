# OpenCode Go cost/peak

La bande au-dessus du champ de saisie affiche le tarif du modèle actuel et son prix par 1M de tokens.

- **Pointe** — rose, avec le temps restant avant la fin de la période.
- **Creux** — vert, également avec un compte à rebours.
- **Unique** — bleu : le modèle n'a pas d'heures de pointe ni creuses.
- **Gratuit** — vert : tous les tokens coûtent 0 $, sans période.

À gauche, le prix du tarif actuel (entrée · sortie · cache, plus l'écriture de cache si le modèle la facture) ; à droite, la phase, la fin de la période dans votre fuseau et le temps restant.

Les réglages se trouvent sur cette page : catalogue des modèles, heures de pointe, comportement, CSS personnalisé et réinitialisation. Le plugin suit toujours la langue de l'interface DSH.
