# OpenCode Go cost/peak

Полоса над полем ввода показывает тариф текущей модели и цену за 1M токенов.

- **Пиковый** — розовый, с обратным отсчётом до конца периода.
- **Льготный** — зелёный, тоже с отсчётом.
- **Единый** — синий: у модели нет пиковых и льготных часов.
- **Бесплатный** — зелёный: все токены по $0, периода нет.

Слева — цена текущего тарифа (вход · выход · кэш, а если модель тарифицирует запись — ещё и запись в кэш); справа — фаза, конец периода по вашему времени и остаток.

Настройки — на этой странице: каталог моделей, пиковые окна, поведение, свой CSS и сброс. Язык плагина всегда совпадает с языком DSH.
